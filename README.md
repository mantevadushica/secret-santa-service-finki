#  Secret Santa Service FINKI

Secret Santa Service FINKI е веб апликација за организирање Secret Santa настани.

Апликацијата им овозможува на корисниците да креираат настани, да покануваат други учесници преку e-mail, да се приклучуваат со уникатен код и да учествуваат во Secret Santa извлекување.

##  Функционалности

- Регистрација и најава на корисници
- Креирање Secret Santa настан
- Генерирање уникатен код за приклучување
- Испраќање e-mail покана со кодот за приклучување
- Приклучување на постоечки настан преку код
- Приказ на сите учесници во настанот
- Wishlist за секој корисник
- Secret Santa извлекување
- Приказ на личноста која корисникот ја извлекол
- Различни права за организатор и обичен учесник

##  Технологии

Проектот е изработен со:

- Vue 3
- Vite
- JavaScript
- Vue Router
- Pinia
- Firebase Authentication
- Firebase Cloud Firestore
- EmailJS

##  База на податоци

За чување на податоците се користи **Firebase Cloud Firestore**.

Во базата се чуваат информации за:

- корисници
- настани
- учесници
- wishlist
- Secret Santa извлекувања

За регистрација и најава се користи **Firebase Authentication**.

##  E-mail покани

- име на настанот
- организаторот
