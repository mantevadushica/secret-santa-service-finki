# Secret Santa Service FINKI

Vue.js стартен проект за веб апликација наменета за сите вработени на ФИНКИ.

## Технологии
- Vue.js
- Vue Router
- Pinia
- Firebase / Firestore
- Vite

## Како да го стартуваш проектот

```bash
npm install
npm run dev
```

Потоа отвори ја адресата што ќе ја прикаже терминалот, најчесто:

```bash
http://localhost:5173
```

## Firebase

Во `src/firebase/firebase.js` замени ги `YOUR_...` вредностите со твојата Firebase конфигурација.

## Страници
- `/` Home
- `/login` Најава
- `/register` Регистрација
- `/dashboard` Dashboard
- `/groups/1` Детали за настан
- `/wishlist` Wishlist
- `/profile` Профил
